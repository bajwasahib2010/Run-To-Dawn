Run to Dawn is a 2D horror platformer created with Godot Engine. The game follows a lost traveler who encounters a mysterious castle and becomes trapped within cursed lands inhabited by supernatural entities.

Players can choose from three playable characters, each with unique strengths, and progress through four atmospheric levels featuring increasingly dangerous enemies, sacred sanctuaries, and bounce-based traversal mechanics. The ultimate goal is to outrun the forces of darkness and return to safety before dawn breaks.

Features

3 playable characters
4 unique horror-themed levels
Multiple supernatural enemies
Bounce-based movement system
Chapel checkpoints and story progression
Atmospheric horror setting
Multiple difficulty phases leading to a final escape sequence
Built with Godot Engine.
